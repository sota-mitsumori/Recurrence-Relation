# 隣接3項間漸化式計算機/Recurrence-Relation

これは、隣接3項間漸化式を自動で解くウェブサイトです。計算ロジックはクライアントサイドのJavaScript（index.html / script.js）で実装されています。</br>
This is the website that allows you to solve the recurrence relation problems.
Calculation logic is implemented in client-side JavaScript (index.html / script.js).

Available at:
https://recurrence-relation.vercel.app/
